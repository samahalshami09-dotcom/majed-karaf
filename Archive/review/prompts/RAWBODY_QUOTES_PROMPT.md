# الخطوة 1 — اقرأ وأبلغ (قبل أي تعديل)

انسخ **بنية** RAW BODY كما هي حرفياً — كل سطر بمفتاحه وقيمته، **مع علامات الاقتباس أو غيابها كما تظهر بالضبط**.

مثال للشكل المطلوب (ليس القيم الحقيقية):
```
"budget_max": {{opportunity.budget_max}},
"property_type": "{{opportunity.property_type}}",
```

⛔ استبدل أي سطر فيه `Authorization` أو `Bearer` أو توكن بـ `[REDACTED]`.

**قف هنا وأبلغ النتيجة قبل أن تعدّل أي شيء.**

# الخطوة 2 — التعديل (نفّذها فقط إن انطبق الشرط)

**الشرط:** إن كان `{{opportunity.sent_project_ids}}` أو `{{opportunity.rejected_project_ids}}` **بلا علامتَي اقتباس** بينما `{{opportunity.property_type}}` **بها اقتباس**:

أضف علامتَي الاقتباس حول حقلَي الدمج النصّيين فقط ليصبحا:
```
"sent_project_ids": "{{opportunity.sent_project_ids}}",
"rejected_project_ids": "{{opportunity.rejected_project_ids}}",
```

⚠️ **لا تلمس `budget_max`** — رقم، ويبقى بلا اقتباس.
⚠️ لا تغيّر أي مفتاح آخر ولا ترتيبه.

احفظ العقدة. **W3 يبقى Draft.**

⛔ لا تسرد خطواتك. لا «سأفتح» ولا «ممتاز، أرى». أعطني هذا فقط:

```

بنية RAW BODY كما هي:
(الأسطر حرفياً بالاقتباسات كما تظهر)

sent_project_ids بين اقتباسين؟      : نعم / لا
rejected_project_ids بين اقتباسين؟  : نعم / لا
property_type بين اقتباسين؟         : نعم / لا

── الخطوة 2 ──
هل انطبق شرط التعديل؟ : نعم / لا
ما عدّلته بالضبط      : ... (أو "لا شيء")

── الخطوة 3 ──
القيمة المكتوبة كما ظهرت بعد الحفظ : (حرفياً)
Status Code                        : ...
Response Body                      : (كاملاً وحرفياً)
next_match_name                    : ... (أو "غير موجود")
الحقل نُظّف بعد الاختبار            : نعم / لا

── تأكيدات ──
W3 لا يزال Draft : نعم / لا
أي SMS أُرسل     : نعم / لا
```
