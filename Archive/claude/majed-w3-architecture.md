## 3. القرارات المعمارية وأسبابها

### أ) حارس مرحلة في **كل** مجموعة — لا مرة واحدة فقط

**السبب:** التسلسل يمتدّ 28 يوماً، و`Stop on Response = OFF`. بلا إعادة فحص، **يُرسَل للعميل الذي حجز معاينة أو انسحب أو تحوّل** — لأسابيع.

**كل حارس مرحلة، فرع None → `Go to` → `Unlock` → END.**

### ب) فرع NO يذهب إلى الانتظار التالي — لا إلى النهاية

**السبب:** **73% من المخزون خارج المطابقة**، فمسار NO هو الأكثر استعمالاً. إنهاء الـworkflow عنده يوقف الرعاية من أول جولة.

**استثناء: المجموعة 8** — فرع NO فيها → `Unlock` → END (نهاية السلسلة).

> 📌 **هذا يعني تغيير وجهة الـ`Go To` الحالية:** من `Unlock` إلى `Wait` التالية، في المجموعات 1–7 فقط.

### ج) القفل يُرفع مرة ويُفكّ عند كل مخرج

| المخرج | يفكّ القفل؟ |
|---|---|
| `L1 → Already Active` | ❌ لا — نسخة أخرى تحمله |
| `Stage Guard → None` (أي مجموعة) | ✅ نعم |
| نهاية المجموعة 8 | ✅ نعم |
| بين المجموعات | ❌ لا — التسلسل مستمرّ |

**عقدة `Unlock` واحدة فقط، وكل المخارج تصل إليها بـ`Go To`.**

## 4. مسار بديل قيد الفحص — الحلقة بدل 8 نسخ

**إن كان `Go To` يقدر أن يستهدف عقدة سابقة**، يسقط 48 عقدة إلى ~8:

```
Trigger → L1 → L2
  → Stage Guard ──┐   ← هدف الرجوع
       Active     │
        → #2 Webhook → Write Match Result → Match Guard
             YES → SMS → Update opportunity ─┐
             NO  ─────────────────────────────┤
                                              ↓
                                        Wait 4 days
                                              ↓
                                    Go To → Stage Guard  ⟲
       None → Go to → Unlock → END
```

**شرط التوقّف:** المحرّك يرجّع `remaining_unsent_count`. عند نفادها يرجّع `NO_MATCH` فيسلك فرع NO دائماً — لكنه **لا يوقف الحلقة**، يبقى يدور بلا إرسال.

**لذلك تحتاج الحلقة حارساً إضافياً للتوقّف.** الخيارات:

| الخيار | التقييم |
|---|---|
| عدّاد إرسالات | GHL لا يزيد قيمة رقمية بسهولة — يحتاج التفافاً |
| حارس على `remaining_unsent_count = 0` | يوقف عند نفاد المخزون لا عند 8 إرسالات — **سلوك مختلف عن السبيك** |
| حارس تاريخي (28 يوماً من الدخول) | ممكن عبر حقل تاريخ — يحتاج تصميماً |

> ⚠️ **الحلقة غير معتمدة بعد.** تحتاج: (1) تأكيد أن `Go To` يستهدف عقدة سابقة، (2) حسم شرط التوقّف. **وحماية GHL من الحلقات اللانهائية غير معروفة.**
