## 3. 🔴 عطل الـbinding — اكتُشف وأُصلح

### التشخيص

عند نسخ مجموعة، **مراجع `response` تبقى مثبَّتة على الويبهوك الأصلي** ولا تتبع النسخة. أُثبت بفحص الربط نفسه لا بالنص المعروض:

```
All fields ▸ Custom webhook ▸ #2 Call Majed… ▸ response ▸ match_found
```

في مجموعة ويبهوكها `#3`.

> **تمييز مهم:** وجهة `Go To` **يعيد GHL ربطها تلقائياً** داخل النسخة (تأكّد في كل المجموعات الثماني). أما مرجع `response` فرابط بيانات يبقى على `action id` الأصلي. **تعميم القاعدة على النوعين هو مصدر الخطأ.**

### 🔴 الاكتشاف الأخطر — `Write Match Result` فيها **ستة** حقول لا اثنان

```
Match Found · Next Match ID · Next Match Name ·
Next Match Type · Next Match Price · Next Match District
```

**وكلها كانت مربوطة بويبهوك المجموعة الأولى.**

> ### ما كان سيحدث لو اعتُمد التوثيق (حقلان فقط)
>
> كل عميل في المجموعات 2→8 يستلم رسالة **سليمة الشكل** تحمل **اسم ومنطقة وسعر مشروع المجموعة الأولى** — لا مشروعه.
